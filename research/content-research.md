# Oak & Bean Coffee — Content Research and Sourcing

## Content approach
Oak & Bean Coffee is a fictional small business created for the WEDE5020 POE. The organisation story, mission, vision, menu descriptions, contact details and page copy were written as original academic content for this project.

## Content used on the website
- Home page: business introduction, featured categories, about preview, location and opening hours.
- About page: organisation story, mission, vision, values and target audience.
- Menu page: coffee, light meals and baked goods with realistic sample pricing.
- Enquiry page: enquiry form for general questions, group visits and booking requests.
- Contact page: address, opening hours, telephone number, email address and directions.

## Image sourcing
All website illustrations in the `images` folder were created specifically for this academic project as original SVG artwork. No third-party images are used in the corrected Part 1 website.

## Technical reference sources
- W3Schools HTML Tutorial — used to review HTML structure, semantic elements, links, images and forms.
- MDN Web Docs — used to review semantic HTML and accessible form structure.
- Visual Studio Code documentation — used for project editing and file organisation.
- GitHub Docs — used for repository and version-control guidance.

## Notes
The business name, address, telephone number, email address, menu items and prices are fictional and are used only for academic demonstration.
